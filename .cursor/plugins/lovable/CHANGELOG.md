# Changelog

## 0.1.0

First release.

- MCP connection to `https://mcp.lovable.dev` over HTTP with OAuth sign-in.
- Skills: scaffold a project, iterate with the agent, manage the Cloud database, deploy.
- Commands: `/lovable-new`, `/lovable-iterate`, `/lovable-db`, `/lovable-deploy`.
- Rules for the Lovable workflow and for safe Cloud database access.
